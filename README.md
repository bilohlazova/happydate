# HappyDate – AI Reminder & Gift Assistant

HappyDate is a SaaS web application that helps users remember important dates, manage people, notes, and get AI-powered gift and message ideas.

Live demo:
https://happydate.vercel.app

## Features

- User authentication (Supabase)
- Events calendar
- Notes system
- Profile management
- AI-powered ideas
- Real-time database
- Responsive UI

## Tech Stack

- Next.js
- React
- TypeScript
- Supabase
- Vercel

## Architecture

Frontend: Next.js + React  
Backend: Supabase (Auth, Database, Realtime)  
Hosting: Vercel
